## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/aastacleanpro/Perplexity-cleaning-march-6.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Perplexity-cleaning-march-6
   ```
3. Install the necessary dependencies:
   ```bash
   npm install
   ```

## Usage
To start the application, run the following command:
```bash
npm start
```
